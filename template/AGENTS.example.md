# AGENTS.md Template

这是目标项目 `AGENTS.md` 的模板，不能复制即用：从零搭建时把 Full Framework 一节复制为 `AGENTS.md`，已有 `AGENTS.md` 的项目只合并 Minimal Snippet 一节。按项目实际情况填写占位内容并删除不适用的条目，路径相对目标项目根目录；接入步骤见 [README.md](README.md)。

---

## Minimal Snippet

```markdown
## 决策笔记

- 修改已有代码或讨论设计方案时，读取 `.agents/skills/decision-notes/SKILL.md`，按其规则检索和维护 `.agents/decisions/`。
- 决策目录不存在表示暂无笔记；仅在确有决策需要记录时创建，不为填模板新增笔记。
- 本次改动涉及笔记、反向指针或关联文件路径时，运行项目已接入的决策笔记校验，查看输出并处理问题；未接入校验器则人工检查本次变更的结构和引用，并在最终回复如实说明。
```

## Full Framework

```markdown
# 项目协作指南

## 项目概况

- 项目用途：<用一两句话说明服务对象与核心功能>。
- 技术栈：<语言、运行时及主要框架，以项目配置为准>。
- 当前范围：<已经实现的能力，以及本阶段明确不做的内容>。

## 目录与入口

- `<源码目录>/`：<核心模块与职责>。
- `<测试目录>/`：<测试组织方式>。
- `<项目说明路径>`：<运行方式及使用说明>。
- `.agents/skills/decision-notes/SKILL.md`：决策笔记的执行规则。
- `.agents/decisions/`：设计意图、非显然约束及被否决的方案。

## 常用命令

以下命令在项目根目录执行；采用项目已有工具，不照搬未接入的命令。

- 安装依赖：<实际命令>。
- 本地启动：<实际命令>。
- 相关测试：<实际命令及如何限定到受影响模块>。
- 类型或静态检查：<实际命令；未接入则删除>。
- 决策笔记校验：<实际命令；未接入则删除>。

## 工作约定

- 修改前阅读目标模块及相关测试，沿用项目已有的命名、错误处理和模块组织方式。
- 项目特有约定：<仅填写无法从工具配置直接看出的必要规则>。
- 对用户已授权的实现与技术选择继续执行；只有超出任务范围或存在必须由用户决定的取舍时才询问。

## 决策笔记

修改已有代码前，读取并遵循 `.agents/skills/decision-notes/SKILL.md`，检索相关决策约束：全局约束、`Applies-To` 匹配的路径、代码中的反向指针，关键词作为补充。涉及架构边界、跨模块契约、持久化格式、重要技术选型或非显然约束时，按该 skill 判断是否记录；机械改动通常不新建笔记，但要维护受影响的已有笔记。目录不存在时视为暂无笔记，首次需要记录时再创建；状态、更新与取代方式、格式及反向指针均以 skill 为准，不在本文件重复定义。

## 验证与交付

- 运行与本次改动相关的测试和检查，明确说明未执行的检查及原因。
- 涉及决策笔记时完成 skill 的收尾清单；已接入校验器则运行并查看输出，未接入则如实说明。
- 代码与对应笔记放在同一次提交里交付；最终回复简述改动、验证结果及笔记变更。
```
